# sphinx-practise
This project is aiming to create a Portfolio page, to understand the basics of Sphinx Engine, focusing on standard practise and techniques used in Documentation as Code philosophy, ensuring the technical capabilities of the documentation engine are utilized. 

The project is hosted using Github Pages, with an eventual integration of Github Action CI-CD pipeline for deployments.

I've decided to reorder the content in such a way there is a custom html page to serve as the homepage.

Every other page is written in Markdown, and would have the content generated.
